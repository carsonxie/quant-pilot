## 1. 个人背景与项目目标

- **知识基础**：统计学、计算机科学与数据科学背景，具备 Python、数据处理和模型研究经验。金融知识仍在学习中；代码和统计基础不自动等于有效的投资判断。
- **资金范围**：少于 10 万人民币的项目专用资金，独立记录其持仓、现金与出入金。首版不管理全部家庭资产或整个券商账户。
- **投资范围**：以境内上市、人民币交易的宽基、行业主题、跨境、商品等 ETF 为主；按需研究债券 ETF。现金单独记账，不与货币基金或短债 ETF 混为一项。
- **收益愿望**：追求长期复利，希望年化收益在 10%–15% 附近，最大回撤尽量低于 20%。这是投资目标，不是软件能够保证的结果。
- **使用方式**：低频决策、人工交易，不做自动下单、高频或日内策略；首版不使用杠杆和做空。
- **投入约束**：每周约 10 小时开发，依赖 Coding Agent 协助实现；日常盘后审核约 10 分钟，需要交易时另在预定可交易时段手动执行并记录。

项目希望最终回答六个问题：现在持有什么；目标持仓是什么；为什么调整；如何在真实资金和交易规则下执行；收益与风险从哪里来；什么证据支持继续使用或修改策略。

## 2. 从讨论2吸收的定位调整

### 2.1 已确认的两项决策

1. **SAA（战略资产配置）先作为比较基准，主动策略独立运行和评估。**首版不强制把真实资金分成核心仓和卫星仓，也不要求主动策略围绕 SAA 比例小幅波动。
2. **只管理专门分配给 Quant-Pilot 的资金。**独立账本可以是券商账户内的一部分；外部持仓和现金不能自动算入项目可用资金。

SAA 基准回答“按预先确定的配置和再平衡规则持有，会怎样”；主动策略回答“择时、选 ETF 和动态权重是否值得增加复杂度”。两者共用数据、产品元数据、成本口径和回测基础设施，但使用独立模拟持仓与净值。

基准的模拟资金不是另一笔真实资金。账户看板不能把基准和主动模拟账户的市值加到真实账户上。基准输出也不能与主动策略买卖建议合并执行。

### 2.2 原有五层漏斗保留为主动策略框架

| 层次 | 职责 | 修订后的边界 |
| --- | --- | --- |
| 宏观择时 | 根据可用市场信息提出风险暴露限制 | 沪深300趋势和全A宽度默认作用于 A 股暴露，不能自动代表黄金与海外市场 |
| 标的筛选 | 排除不满足数据、产品和交易条件的候选产品 | 区分“不能买入”“无法评估”“当前不能交易”，保留已有持仓 |
| 截面打分 | 对可选 ETF 排名 | 因子是候选预测信号，排名靠前不等于已证明存在 Alpha |
| 权重配置 | 将策略选择转换成目标权重 | 明确等权、波动率倒数、方差倒数；复杂优化需要比较证据 |
| 风控 | 修改目标、限制新增风险并提出退出建议 | 明确作用范围和优先级；普通再平衡不能抵消风险退出 |

原来“全市场最优 3–5 只”改为“给定候选池及规则下的 Top K”。池大小和 K 是配置及研究选择，不是已被证明的最优值。

### 2.3 四块新增或深化的需求

| 需求 | 需要解决的问题 |
| --- | --- |
| 配置基准与再平衡 | 固定配置是否已足够；再平衡本身有什么效果；主动调整有什么增量 |
| 账户与执行闭环 | 策略目标、真实账户、交易建议、执行反馈分别是什么，如何核对 |
| ETF 池管理 | 想获得何种资产暴露、选择哪只产品、今天是否可交易、最终是否持有 |
| 分层归因 | 持仓盈亏、执行偏差、相对基准表现、因子暴露和风险贡献分别回答什么 |

估值定投、网格、目标波动率、双动量，以及核心／卫星结构保留为研究候选，不自动列为首版必做策略。

## 3. 技术选择及工程边界

保留 Python + uv、Polars / pandas / numpy、DuckDB、按需 Parquet 缓存、自研轻量日线回测、vectorbt 对照、Streamlit + Plotly 和轻量调度。

Akshare 为主要候选数据入口，采用限流、重试、来源记录和质量检查，不假定接口无限可用。JQData 等按权限和覆盖启用，未获得数据时标注交叉验证缺失。

DuckDB 继续作为本地主要存储。首版采用统一写入口和批量事务，面板与定时任务不能无协调地并发修改账户。行情缓存可以重建，真实成交和账户事件不能由策略重算覆盖。并发实现应遵循所锁定版本的 [DuckDB 官方并发说明](https://duckdb.org/docs/current/connect/concurrency.html)。

项目按已有仓库渐进演进；不预建大量空模块，不强制引入 MLflow、Airflow、Kafka 或服务集群。具体文件拆分由后续 plan.md 确定。

## 4. 统一后的金融与统计概念

本节替代旧版中不准确或过于绝对的“最高硬约束”。确定性的记账和时间规则必须执行；经济效果需要验证。

### 4.1 信息时间、价格与成交

- 盘后策略使用 T 日收盘后已可获取的信息，最早在下一可交易时段执行；不能用同一收盘价假装已经成交。
- 统计日期、正式发布日期、实际可用时间与抓取时间不同。回测使用当时可用的数据版本，低频前向填充必须发生在发布时间对齐之后。
- 跨境资产处理时区、市场休市、底层市场收盘先后和净值估算时间，不能把同一日期标签视为同步信息。
- 原始成交价用于真实份额和现金记账；指标使用定义明确、可重现的复权或总收益序列。现金分红不得既包含在总收益价格中，又重复加入组合收益。
- 当前复权序列可能因后续分红变化，缓存需要失效或版本化；不能机械拼接“旧前复权历史＋新前复权增量”。
- T+0/T+1 回转交易限制与资金交收、可用、可取规则分别建模，不用“交收日期差一天”替代交易场景验证。具体规则以交易所和产品资料为依据。[上交所 ETF 常见问题](https://www.sse.com.cn/assortment/fund/etf/question/)

### 4.2 收益、配置和风险

- 算术收益 r = P_t / P_(t-1) − 1；对数收益 g = ln(P_t / P_(t-1))。根据研究用途选择并记录，不强制所有训练都使用对数收益。
- 同一期组合简单收益使用期初权重对资产简单收益加权；不能把资产对数收益直接加权当作精确组合收益。
- 波动率倒数为 w_i ∝ 1/σ_i；方差倒数为 w_i ∝ 1/σ_i²。两者不同，也都不保证收益或回撤优于等权。
- 组合波动 σ_p = sqrt(wᵀΣw)；MRC_i = (Σw)_i / σ_p；RC_i = w_i × MRC_i。等风险贡献比较 RC_i，不能只比较 MRC_i。
- 价格止损、ATR 止损、趋势过滤和再平衡应比较适用条件，不给任何一种贴上必然专业或业余的标签。
- 分散可能改善风险，但相关性随时间改变，不能保证实际最大回撤降低，黄金与债券也不能保证每次危机都对冲。
- 成本按实际或标注的模拟费率计算，佣金、最低收费、价差、滑点与冲击分别定义。旧版“双边佣金至少0.15%”不再作为统一市场事实。

### 4.3 因子、IC与研究证据

- 候选因子是定义明确的可计算特征，预测作用需要验证；预测因子与解释风险的因子模型不能混为同一对象。
- RankIC_t 是当期可比标的因子得分与未来指定期限收益的 Spearman 秩相关；没有到固定两两胜率的一般换算。[SciPy 官方定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.spearmanr.html)
- ICIR = mean(IC_t) / std(IC_t)，需标明频率、期限、样本数、有效截面数量及年化方式；缺少观测或方差为零时不输出虚假有效值。
- 组合 IR 衡量相对基准的主动收益与跟踪误差，区别于 ICIR；不能把 CAGR 差值直接当作所有情形下的年化平均主动收益。
- ETF 样本少且相关性高，不照搬几千只股票的分组数、IC阈值或显著性标准。
- IR ≈ IC × sqrt(BR) 有假设条件，BR 是有效独立决策广度，不能用“ETF数量×调仓次数”直接得到。
- 收益窗口重叠或时序相关时，普通独立样本 t 检验不充分；采用适当的稳健误差或分块重采样，并记录多重试验次数。
- 去极值、标准化、中性化、差分或 ADF 检验由用途和模型假设决定。ETF 行业轮动默认保留行业差异，ETF 规模不等于其成分股市值风格。
- 连续信号和布尔规则均可使用，前提是定义清晰、可复现且经过验证。

### 4.4 收益贡献、归因和技能判断

持仓贡献回答“哪只 ETF 贡献了多少钱”；风险贡献回答“谁主导风险”；基准归因回答“为什么偏离基准”；因子模型回答“所选风险来源能解释多少收益”。

Brinson 的配置、选择及交互贡献不直接等同于“宏观择时＋市场 Beta＋真实 Alpha”。回归截距只是相对于所选模型的 Alpha 估计，不是自动认定的投资能力。[CFA Institute 归因说明](https://rpc.cfainstitute.org/research/cfa-digest/2017/04/using-brinson-attribution-to-explain-the-differences-between-time-weighted-twr-and-money-weigh)

信号触发原因属于事前解释，不能冒充事后归因。单次不执行后赚钱或亏钱，也不能证明人工判断长期有效。

## 5. 日常使用与账户纪律

| 时点 | 用户操作 | 系统支持 |
| --- | --- | --- |
| 盘后审核 | 检查数据、账户更新时间、待处理建议和原因 | 最新估值时间、目标与实际偏离、建议状态、风险事件 |
| 需要交易时 | 在预定时段审核现金与可卖份额，手动执行 | 数量、参考价与时间、费用估计、优先级、卖出未成时的买入依赖 |
| 交易后 | 记录成交、部分成交、拒绝、延迟及原因 | 手动录入或标准 CSV，重复导入不重复计账 |
| 资金变动时 | 记录项目入金、出金与初始余额 | 现金流与投资盈亏分离，账户可核对 |
| 周／月复盘 | 看是否持续偏离目标、数据或执行异常 | 简洁异常汇总与基准比较 |
| 策略评审 | 按预定条件决定观察、暂停或恢复 | 策略版本、证据与状态变更记录 |

“目标与昨天相同”不代表可以跳过审核：价格漂移、未成交和出入金仍可能要求调整。避免无计划盯盘，但不把“绝不打开交易软件”写成与人工执行冲突的规则。

## 6. 风险清单：工程检查与研究假设分开

以下研究问题允许被证伪；不得修改历史样本、筛掉失败结果或重复使用测试集，强行达到旧版的改善比例。

| 编号 | 风险 | 工程上必须做到 | 研究中需要回答 |
| --- | --- | --- | --- |
| H1 | 震荡市反复交易、成本磨损 | 输出次数、换手与成本；阈值和最低持仓不阻断风险退出 | 加入宽度、波动率、缓冲带后，扣费表现与换手怎样变化 |
| H2 | 流动性和可成交性幻觉 | 使用下一可交易时段、可卖份额与成交限制；报告交易额占历史成交额比例 | 不同筛选和冲击假设下，策略增量是否仍存在 |
| H3 | 参数挖掘、样本外污染 | 固定版本，记录全部试验，保留未用于选规则的测试区间 | 参数邻域和不同时间窗口的证据是否一致 |
| H4 | 数据源静默失效 | 价格、日历、时效、复权检查；缺失不得当通过 | 替代来源、覆盖和延迟是否改变结论 |
| H5 | 目标被误当作成交 | 四类记录分离，按反馈更新账户，重复操作有保护 | 延迟、部分成交、人工覆盖如何影响结果 |
| H6 | 风格变化与策略衰减 | 保存观察证据、暂停原因和恢复条件 | 衰减源于噪声、暴露变化，还是原假设失效 |
| H7 | ETF池事后选择、假分散 | 保存历史入池依据及元数据；报告暴露和相关性 | 去冗余与产品选择是否改善成本和风险 |
| H8 | 收益来源解释错误 | 出入金不记盈利，贡献可核对，Alpha与误差分别展示 | 主动策略增量是否稳定且有经济意义 |

- 摩擦成本以金额及相对资本的基点报告；“成本／总收益”在零收益和负收益时会误导。
- 人为提高冲击假设后收益下降，并不能单独证明历史超额收益都是流动性幻觉。
- 相关性阈值、改善30%或50%、每种风格都赚钱、三个月IC为负自动降权，均不是未经验证的共同上线规则。
- ETF 仍有终止运作、流动性、跟踪及折溢价风险，不能推出“数据无瑕疵、没有容量限制”。[投委会 ETF 风险说明](https://www.ifec.org.hk/web/sc/investment/investment-products/etf/benefits-and-risks/major-risks.page)
- 缺少历史完整产品池时，标注“以指定产品池为条件的研究”，不宣称无生存者偏差。

## 7. 分阶段学习路线

| 知识主题 | 学习时机 | 掌握后的可观察结果 |
| --- | --- | --- |
| ETF交易、价格分红、ATR状态 | Phase 0收尾 | 手工核对完整买卖与分红案例，解释触发和成交差别 |
| 算术／对数收益、倒数配置 | Phase 0收尾 | 算出等权、1/σ、1/σ²的差异 |
| SAA、再平衡、现金流、账户核对 | Phase 0.5 | 目标不变但权重漂移时正确调整；入金不算收益 |
| ETF产品、指数暴露、历史可用性 | Phase 0.5 | 区分同指数替代品和不同但相关的资产 |
| 单因子、RankIC／ICIR、简单组合 | Phase 1 | 完整复现少量因子的有效或无效结论 |
| 样本划分、多重试验、时序验证 | Phase 0.5开始，Phase 1强化 | 指出哪些数据已用于选规则，测试窗口为何仍独立 |
| 协方差、风险贡献、收缩与风险平价 | Phase 1.5 | 验证RC加总，解释约束下不能等风险的情况 |
| 绩效归因、模型Alpha、执行偏差 | Phase 1.5 | 区分基准贡献、因子解释、费用和残差 |
| 策略生命周期、行为偏差 | 纸上运行开始，Phase 1.5系统化 | 按证据评审，不随近期盈亏任意改规则 |
| ML、Purging／Embargo、SHAP | Phase 2可选 | 定义跨期标签泄露边界，对照简单模型，接受无增量 |
| Black-Litterman、因子择时、Barra | 远期按需 | 说明所解决的问题及估计假设 |
| 微观结构、宏观日历、VaR／ES、A股制度 | 持续积累 | 对应到数据、成本、暴露或压力场景 |

## 8. 研究与工程的完成标准

1. **工程完成**：公式、时序、账本、重跑与错误处理满足 spec，有可复核证据。
2. **研究完成**：按预先记录的方法完成比较，结论可为有效、无效或证据不足。
3. **允许使用真实资金**：另行检查账户、配置、数据、缺陷与策略证据，工程完成不自动触发投入。

实验追踪从规则阶段开始，不等到 ML。失败实验也保留。复杂度由具体问题与增量证据支持，不按阶段必然增加。

实际最大回撤可能超过历史值。收益目标不能成为让 Agent 持续调参的任务；反复用于选规则的测试数据应重新归类为验证数据。
