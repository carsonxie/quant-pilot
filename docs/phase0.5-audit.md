### C01 / A — "波动率倒数"实为 1/σ²

- **原口径**：波动率倒数加权 w_i ∝ 1/σ_i（讨论2.md:41 原意）；task.md T0.5 按 1/σ² 实现。
- **实际证据**：`src/strategies/portfolio_optimizer.py:3-4,11`（docstring 与注释 `w_i ∝ 1/σ_i²`）；`:187-188` 调 `_calc_inverse_var_weights`；`:256-279` 实现 1/σ²；`:51` `PortfolioResult.method` 默认 `"inverse_volatility"`；`config/settings.yaml:100` `method: "inverse_volatility"` —— 名称与行为不符。测试 `tests/test_portfolio_optimizer.py:158-176` 只验证单调性/等权，无 2:1、4:1 独立期望值。
- **影响范围**：策略目标权重输出；已入库 11 条信号（3 个信号日）。
- **新口径**：inverse_volatility = 1/σ（默认，恢复原意）；inverse_variance = 1/σ² 保留为对照；`method` 标签与实际行为一致并进入推送/面板版本信息。
- **验证方式**：独立期望值测试：σ={10%, 20%} 且无约束时 1/σ 权重比 ≈2:1、1/σ² ≈4:1；两方法不混用（结果 `method` 字段一致）。
- **迁移/历史影响**：旧信号保留不覆盖（同日重跑会 UPSERT 覆盖 → 只对新日期生成 v0.2 目标）；旧口径在记忆与本文档标注；受影响回测/报告重跑并列新旧。
- **修改与验证摘要**（2026-09-14, M1-1-02）：`PortfolioOptimizer(method=...)` 按标识分派 `_calc_inverse_vol_weights`(1/σ) 与 `_calc_inverse_var_weights`(1/σ²)；`method` 标签贯穿结果与信号原因；settings/docstring 更新。独立期望值测试：σ={10%,20%} → 2:1 / 4:1（`TestWeightMethods`）；公开 API 构造 σ 比 2 → 权重 (0.30, 0.15) 恰为 2:1；未知方法拒绝。真实数据对比（只读）：510050 权重 1/σ=7.6% vs 1/σ²=13.0%，方法可区分。全量 260/260 通过。
