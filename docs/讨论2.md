什么叫做 “被动指数型”还是“主动量化/增强型”？还有 你提到别做二选一 要多种配置，我一直想做但不知道怎么做 都是手动在调，怎么样用算法和程序来 做告诉我思路？比如沪深300，1000，科技，红利，等等行业etf 或者黄金 纳指etf，一开始怎么确定比例，然后比如每周看一次 怎么确定‘偏离目标’就卖出或买入 把资金在不同etf之间调整？这个专业的说法叫什么？这样子做是不是能更好对冲风险 比买一两个要盈利的可能性更高？


## 一、先补上那个概念：被动 vs 主动量化/增强

| 类型                      | 谁决定持仓                 | 目标                         | 怎么识别                                                         |
| ------------------------- | -------------------------- | ---------------------------- | ---------------------------------------------------------------- |
| **被动指数型**      | 指数编制方案（规则写死的） | 复制指数，跟踪误差越小越好   | 招募书里写"投资标的指数成分股比例不低于90%"，名字常带"ETF""指数" |
| **主动量化/增强型** | 基金经理的模型+主观判断    | 跑赢某个基准（如沪深300+5%） | 名字带"增强""量化精选"，持仓和指数只有部分重合，费率更高         |

对你来说区别很实际：被动型你查指数就知道持仓， **规则透明、可预期** ；增强型你买的是经理的能力，能力会变、会离职、会风格漂移。做资产配置时， **底仓工具优先用被动型** ，因为你是在配置"资产"，不是在赌"经理"。

## 二、你想做的这件事，专业说法叫什么

整套东西的学名是： **规则化资产配置（Systematic Asset Allocation）+ 再平衡（Rebalancing）** 。拆开是几个术语：

* **战略资产配置（SAA）** ：定长期目标比例（如股票70%/黄金10%/现金20%），几年才改一次。
* **战术资产配置（TAA）** ：在SAA基础上做小幅偏离（±10%以内）博短期机会—— **新手建议先不做** 。
* **再平衡（Rebalancing）** ：把漂移掉的权重拉回目标。两种主流触发方式：
* **日历再平衡** （time-only）：固定每月/每季/每年调一次；
* **阈值再平衡** （threshold / percentage-of-portfolio）：偏离超过设定带（band）才调；
* 你说的"每周看一次、偏离才动"=  **周期检查 + 阈值触发（hybrid rebalancing）** ，是机构最常用的组合，兼顾成本和纪律。
* **初始定比例的方法** ：等权法、 **风险平价/等风险贡献（Risk Parity / ERC）** 、均值-方差优化（Markowitz）、核心-卫星（Core-Satellite）。
* 分散带来的额外收益有个有趣的名字： **再平衡红利 / 波动率收割（rebalancing bonus / volatility pumping）** 。

## 三、初始比例怎么定（三种由简到繁）

**方法A：核心-卫星经验法（推荐起步）**

* 核心仓 60–70%：宽基+防御（沪深300、红利低波、黄金、货币/短债）
* 卫星仓 30–40%：弹性资产（中证1000、科技/科创、纳指）
* 示例：沪深300 20%｜红利低波 15%｜中证1000 10%｜科技 10%｜纳指 15%｜黄金 10%｜现金/短债 20%

**方法B：波动率倒数法（风险平价的穷人版）**
用各资产过去1–3年的周收益波动率 σ，权重 wᵢ ∝ 1/σᵢ，再归一化。效果：黄金、红利这类低波动资产自动多配，科技、1000自动少配，让 **每个资产对组合风险的贡献大致相等** 。比拍脑袋科学，且不需要预测收益。

 **方法C：均值-方差优化** ——需要预期收益和协方差矩阵，估计误差会被优化器放大成极端权重（全仓某个资产）， **个人不建议裸用** ；要用就加约束（单资产上限25%、下限5%）。

起步建议：A定框架，B做微调，跑一年后再修订。

## 四、周频检查 + 阈值触发的具体规则

1. **检查频率** ：每周五收盘后算一次权重（检查便宜，交易贵）。
2. **触发带（band）** ：

* 绝对阈值：|当前权重 − 目标权重| ≥  **5个百分点** ；
* 或相对阈值：偏离 ≥ 目标权重的  **25%** （目标10%的资产，到7.5%或12.5%触发）；
* 高波动资产（科技、1000）带宽放宽到6–8pp，低波动资产（红利、黄金）收紧到4pp。

1. **调多少** ：出带后 **调回目标权重** （简单）；或只调回带边界（省成本，换手更低）。
2. **成本过滤** ：单笔调仓金额 < 总资金1% 或不足一手（100份）时跳过，累积到下次。
3. **现金腿参与计算** ：把货币基金/活期也算作一个资产，否则权重全是错的。
4. **SAA年审** ：每年固定一天（如生日）审视目标比例本身要不要改（年龄、收入、风险承受变化），平时只执行不改规则。

## 五、程序化落地思路（半自动就够）

```
配置(yaml) → 拉行情 → 算权重 → 判断出带 → 生成调仓单(取整100份) → 推送给你 → 人工下单 → 记日志
```

示意代码（数据源可用 akshare / tushare 的场内ETF行情）：

```python
targets = {"510300":0.20, "512890":0.15, "512100":0.10,
           "588000":0.10, "513100":0.15, "518880":0.10, "cash":0.20}
band = {"default":0.05, "588000":0.08, "512100":0.08}   # 高波动放宽

prices  = get_close_prices()          # 每周五收盘后跑
shares  = load_holdings()             # 本地csv/json记录
values  = {k: prices[k]*s for k, s in shares.items()}
total   = sum(values.values())
w       = {k: v/total for k, v in values.items()}

for k, tw in targets.items():
    b   = band.get(k, band["default"])
    dev = w.get(k, 0.0) - tw
    if abs(dev) >= b:
        delta = -dev * total                       # 调回目标所需金额
        lots  = int(delta / (prices[k]*100))       # 取整到100份
        if lots != 0: print(f"{'买入' if lots>0 else '卖出'} {k} {abs(lots)}手")
```

* **半自动** ：脚本 + 系统定时任务（cron/任务计划），结果推微信或邮件，你手动下单。对个人完全够用，还保留一道人工保险。
* **全自动** ：券商量化终端（QMT/miniQMT、Ptrade），有资金门槛且各券商不同，等你规则跑顺了再升级。
* **回测先行** ：用历史周频数据对比"买入持有 vs 月再平衡 vs 周检查+5%带 vs 8%带"，看**夏普比率、最大回撤、换手率、成本**四个指标，选一个你拿得住的规则。工具：pandas手写、backtrader、vectorbt 都行。

## 六、诚实地回答"是不是更好"

**是的部分：**

* 分散低相关资产（A股/美股/黄金相关性低）能 **显著降低组合波动和最大回撤** ，这是数学上确定的；
* 规则化再平衡强制"高卖低买"，在震荡市有再平衡红利，且 **最大的价值是治追涨杀跌** ——长期投资者亏钱的主因是行为，不是资产；
* "拿得住、睡得着"直接提高你 **实际拿到正收益的概率** 。

**不一定/要警惕的部分：**

* 期望收益 ≈ 各资产期望的加权平均， **分散本身不创造超额收益** ，全仓押中最强资产的人短期一定比你赚得多（只是没人能事前知道是谁）；
* 危机时股票类资产相关性会骤升（correlation breakdown），真正对冲的是黄金/债券这条腿，别全配股票类"假分散"；
* 趋势单边市里再平衡会拖累收益（卖掉一直在涨的），要有心理准备；
* 频繁调仓的成本会吃掉再平衡红利，所以才有"阈值带+成本过滤"。

一句话总结：**这套方法买的不更高收益，而是"更大概率的、你能坚持到的收益"。** 对绝大多数个人投资者，这已经是能拿到的最好结果。

## 一、小额个人投资者可用的量化方法清单

除了"SAA+再平衡"这个底仓框架，下面这些方法 **低频、规则明确、小资金友好** ，按上手难度排序：

### 1. 估值分位定投（最简单，先做这个）

不改变定投纪律，只改变 **每期投入金额** ：

* 用指数的 PE/PB 历史分位（近10年）决定系数：分位<20% → 投1.5倍；20–40% → 1.2倍；40–60% → 1倍；60–80% → 0.6倍；>80% → 停投或部分止盈。
* 进阶版用  **ERP（股权风险溢价）= 1/PE − 10年国债收益率** ，ERP分位越高股票越便宜。这就是你之前问"什么时候买红利"那个问题的程序化版本。

### 2. 趋势过滤（时序动量 / 绝对动量）

对每只持仓ETF加一条规则： **收盘价 < 200日均线（或近12个月收益为负）时，把该仓位换成货币/短债，回到均线上方再买回** 。

* 这是 Gary Antonacci 的 GEM（Global Equity Momentum）的一半，历史回测能明显砍掉最大回撤（代价是牛市里偶尔被洗出去、有磨损成本）。
* 注意：趋势法在震荡市会反复打脸（whipsaw），所以带宽要设缓冲（如跌破97%均线才卖、涨回103%才买），且只对宽基/大类资产用，不对行业ETF滥用。

### 3. 截面动量轮动（你那个"在池子里下功夫"想法的标准答案）

每月（或每季）固定一天：

* 计算池内每只ETF的动量得分（常用： **近12个月收益剔除最近1个月** ，避免短期反转污染）；
* 买入得分最高的前 N 只（N=2~4），等权持有；
* 下期重算，出榜就换。
* 叠加第2条：如果榜首ETF绝对动量也为负，这部分钱进货币基金。这就是完整的双动量。
* **频率别高于月度** ——周度轮动对个人来说成本和心理负担都太重，学术上也主要是月频动量显著。

### 4. 网格交易（只适合震荡型资产）

对红利低波、宽基这类"长期不死但波动大"的标的：以基准价为中心，每跌5–8%买一档、每涨5–8%卖一档，档位资金预先分好。

* 优点：机械执行、震荡市持续薅小钱；
* 缺点： **单边下跌会越买越套（要设总仓位上限），单边上涨会过早卖飞** 。所以网格只用于"你确信不会归零、且长期有底"的资产，行业主题ETF慎用。

### 5. 目标波动率（Target Vol）

仓位 = 目标波动率 ÷ 该资产近60日实现波动率（封顶100%）。波动放大自动降仓，波动收敛自动加仓。个人可简化为：某ETF近20日波动率超过其历史80分位时，仓位砍半。

 **不建议碰的** ：因子择时（需要很强的研究能力）、机器学习选股（小样本极易过拟合）、日内策略（费率和执行速度都不占优）。

## 二、池子要不要精挑细选？——要，而且分两层

### 第一层：产品层筛选（同类指数选哪只ETF）

这是 **硬门槛** ，一票否决制：

| 指标       | 门槛                                             | 为什么                     |
| ---------- | ------------------------------------------------ | -------------------------- |
| 规模       | > 5亿（最低2亿）                                 | 太小有清盘风险、盘口薄     |
| 日均成交额 | > 3000万                                         | 你买卖不吃大价差           |
| 跟踪误差   | 同类中最低的一档                                 | 这是被动基金的核心KPI      |
| 费率       | 管理费+托管费越低越好（0.15%–0.6%区间差异很大） | 长期复利下0.4%的差距很可观 |
| 折溢价     | 常年贴水/溢价的避开（跨境ETF尤其注意）           | 溢价买入=直接亏差价        |

例：同样跟踪红利低波指数的七八只ETF，过完这五关通常只剩1–2只， **这一步没有主观判断，纯规则** 。

### 第二层：指数/风格层选池（池子里放哪几类资产）——这才是真正"下功夫"的地方

**原则1：覆盖要全，冗余要删。**

* 覆盖：A股大盘（沪深300）、中小盘（中证1000）、成长（科创/创业板）、价值（红利）、海外（纳指/标普）、另类（黄金）。
* 删冗余：把候选池所有ETF的**近3年周收益率相关系数矩阵**算出来，相关系数 > 0.85 的视为同一风格， **只留第一层筛选过关的那一只** 。比如上证50和沪深300相关性极高，留一个即可。

**原则2：入池用历史体检（回溯性量化指标），但别用它们预测未来。**
给每个候选指数打分，示例：

| 维度 | 指标                                 | 看什么             |
| ---- | ------------------------------------ | ------------------ |
| 质量 | ROE中位数、盈利稳定性                | 成分股是不是真赚钱 |
| 估值 | PE/PB 历史分位                       | 现在贵不贵         |
| 动量 | 近12个月超额收益                     | 趋势是否健康       |
| 风险 | 最大回撤、波动率                     | 你拿不拿得住       |
| 分红 | 股息率及其可持续性（分红率是否<60%） | 红利类必看         |

**原则3：池子本身低频维护。**
每半年（配合指数调样月6月/12月）复审一次：出局的替换、新指数（如新出的行业ETF）考察满1年数据后才准入。 **池子稳定是策略稳定的前提** ——池子天天换，动量轮动就变成了追热点。

## 三、把两层拼起来的完整架构

```
SAA（年度审定）
├── 70% 核心：宽基 + 红利 + 黄金 + 债基  ← 只做"再平衡 + 估值分位定投"
└── 30% 卫星：动量轮动池（6–10只精选ETF） ← 月频截面动量 + 绝对动量过滤
```

轮动部分伪代码：

```python
pool = ["510300","512100","588000","513100","518880","512890", ...]  # 第一、二层筛完
score = {}
for etf in pool:
    mom12 = ret_12m(etf) - ret_1m(etf)      # 12-1动量
    score[etf] = mom12

top = sorted(score, key=score.get, reverse=True)[:3]
for t in top:
    if ret_12m(t) <= 0 or close(t) < ma200(t):   # 绝对动量过滤
        top.remove(t)                             # 该份资金进货币基金
# 等权买入 top，下月同日重算
```

## 四、三个必须说的泼冷水

1. **过拟合是最大的敌人** 。参数（12-1、前3名、200日线）都是历史上"事后看起来好"的组合。对策：只做参数敏感性测试——把12改成9、把3改成4，结果如果天差地别，说明策略是拟合出来的噪声，不能用；结果平滑变化才可信。
2. **回测好 ≠ 实盘好** 。务必计入双边费率+冲击成本（ETF按万5–万10估），并预留"策略连续跑输基准一年"的心理预算——动量策略历史上都出现过这种阶段，扛不住就会在最差时刻弃用。
3. **先纸上跑6个月** 。规则定好后不投真钱，每月手动记录一次模拟调仓，对比回测和"你的模拟盘"的差异，同时检验自己能不能坚持执行。这一步淘汰掉的策略比回测淘汰的还多——很多规则败给的不是市场，是执行者的手痒。

# 问题3 因子

很多专业量化研究员在做的‘因子挖掘’是哪个阶段和层面做的事情，是要解决什么问题？‘因子’指的是什么什么可以作为一个因子？是不是很难 讲讲大概的完整流程是怎么样的？ 建议我做吗或者说到哪个阶段才可以做？



## 一、"因子"到底是什么

一句话定义：**因子是一个能给每只股票打分的、可计算的数值，且这个分数与未来收益存在统计上的相关性。**

它不是玄学，本质上是"把某种投资逻辑翻译成一列数字"。

| 因子大类 | 具体例子                               | 可计算定义                                 | 背后的经济学故事          |
| -------- | -------------------------------------- | ------------------------------------------ | ------------------------- |
| 市场     | Beta                                   | 个股对市场回归的斜率                       | 承担系统性风险的补偿      |
| 规模     | Size                                   | ln(总市值)                                 | 小盘流动性差、风险高      |
| 价值     | EP / BP / SP                           | 净利润÷市值、净资产÷市值                 | 承担了破产/困境风险       |
| 动量     | 12-1 Momentum                          | 过去12个月收益剔除最近1个月                | 反应不足 + 资金追逐       |
| 反转     | 短期反转                               | 过去20日收益取负                           | 反应过度                  |
| 质量     | ROE、毛利率、应计项                    | 净利润÷净资产；(净利−经营现金流)÷总资产 | 好公司溢价 / 财务操纵折价 |
| 成长     | 盈利增速、SUE                          | 净利同比；标准化未预期盈余                 | 盈余公告后漂移            |
| 波动     | 低波/特异波动率                        | 过去1年日收益标准差                        | 彩票偏好导致高波股被高估  |
| 流动性   | Amihud非流动性                         | \|收益\|÷成交额 的均值                    | 流动性溢价                |
| 资金流   | 北向持股变化、大单净额                 | 数据商提供                                 | A股特有的信息优势因子     |
| 另类     | 分析师上调、新闻情绪、招聘数据、卫星图 | NLP/爬虫/外购                              | 信息处理速度差            |

**几乎任何能算出来的东西都可以试着当因子**——包括"公司名字字数""CEO年龄""办公地纬度"。所以关键不在于"能不能算"，而在于第二、三节的检验和证伪。

学术脉络供你有个坐标：CAPM（1因子）→ Fama-French 三因子（+规模、价值）→ Carhart 四因子（+动量）→ FF 五因子（+盈利、投资）→ 中国市场专用模型如 Barra CNE5/CNE6（含流动性、Beta、非线性规模等）。这些是"已被承认的公共因子"，机构研究的战场在它们的残差里。

## 二、因子挖掘在解决什么问题

它同时服务于**三个完全不同的目的**，混淆这三者是新手最大的误区：

### 目的一：找 Alpha（进攻）

构建能预测未来收益的因子，选股、择时、择风格。这是外人以为的"量化"，也是竞争最惨烈的地方。

### 目的二：风险归因（防守，最被低估）

你赚的钱到底是**本事**还是**运气/风险暴露**？

- 某私募年化20%，做因子归因后发现：市值因子贡献12%、价值因子贡献5%、真alpha只有3%——他其实是个加杠杆的小盘价值玩家。
- 对你也有用：你以为自己在做"聪明的红利+动量策略"，一归因发现90%的收益就是A股整体beta。这认知价值千金。

### 目的三：风险模型与产品化（工程）

- **协方差估计**：几千只股票的协方差矩阵直接估会爆炸，用因子模型（Barra式）把它压缩成"几十个因子的协方差 + 残差方差"，这是组合优化器能跑起来的前提。
- **Smart Beta 产品**：你买的红利低波ETF，本身就是"因子挖掘"的工业化成品——中证指数公司挖好了、写成编制方案、发成产品卖给你。

所以，**因子研究处于"数据层"之上、"组合构建层"之下**：

```
数据 → 【因子研究】 → 因子合成/打分 → 组合优化 → 风控 → 交易执行 → 绩效归因
                              ↑________________________________|
                                    （归因结果反哺因子研究）
```

## 三、为什么难（六个硬约束）

1. **信噪比极低**。一个优秀因子的月频 Rank IC 也就 0.03–0.06。意味着因子对收益的解释力**不到1%**，剩下99%是噪声。你的结论建立在成千上万个观测的统计规律上，单次判断几乎必然错。
2. **多重检验 / p-hacking**。测1000个因子，纯靠运气也会有50个 t>2。Harvey 等人因此提出金融因子的显著性门槛应该是 **t > 3.0**（对应p<0.001），而不是社科惯用的2.0。McLean & Pontiff 的研究显示，因子论文发表后收益平均衰减约 58%——一半是风险溢价被套利掉，一半本来就是数据挖掘的幻觉。
3. **拥挤与衰减**。好因子被发表 → 资金涌入 → 收益消失甚至反转。价值因子 2018–2020 年被"杀死"了三年，2021 年又复活。你得判断：这是暂时回撤，还是永久失效？机构都判断不了。
4. **数据是最贵的部分**。回测需要 **Point-in-Time（PIT）数据库**：即"当时能看到的数据"，而不是"现在修正后的数据"。财报会重述、会追溯调整、股票会退市。用今天的财务数据回测十年前 = 未来函数，回测收益率能虚高一倍。国内 PIT 数据（Wind、聚源、通联）年费数十万，**个人几乎拿不到干净版本**，这一条就足以劝退。
5. **成本与容量**。高换手因子的毛收益可能80%被摩擦成本吃掉。回测不算 T+1、涨跌停不可成交、停牌、卖出印花税（千一）、冲击成本，结果全是假的。
6. **A股特有机制**：壳价值扭曲小市值因子、财务造假、退市机制不完善、指数编制规则、ETF申赎带来的被动资金流、政策驱动的板块效应。照搬美股因子经常失灵。

## 四、完整流程（机构标准版，7个阶段）

### Stage 0：数据与基础设施

清洗对齐：复权价格、停复牌表、ST标记、退市股保留（否则幸存者偏差）、财报披露日对齐（防未来函数）。

### Stage 1：因子构造

想法来源：学术论文、卖方金工研报（华泰、开源、方正、广度的因子系列质量很高且免费）、产业逻辑、另类数据、遗传规划/神经网络自动生成表达式。

**定义必须精确到可复现**，例如：

```
EP_TTM = 最近四个季度归母净利润之和 / 当日总市值
时点：财报数据取"截至当日已披露"的最新值
缺失：行业内中位数填充 or 直接剔除
更新：月度，财报季后重算
```

### Stage 2：预处理（A股必做）

```python
# 1) 去极值：MAD法，中位数 ± 3×1.4826×MAD 截断
# 2) 标准化：z-score，使因子可比、可合成
# 3) 中性化：对 ln(市值) 和行业哑变量做截面回归，取残差
#    —— 否则你挖出的"新因子"可能只是小盘因子的马甲
```

中性化这一步是区分业余和专业的分水岭。**没有中性化的因子检验，90%是在重新发现规模效应。**

### Stage 3：单因子检验（核心）

```python
import pandas as pd, numpy as np

# factor: DataFrame(index=调仓日, columns=股票, values=因子暴露)
# fwd_ret: 同结构，未来N日收益

ic = factor.corrwith(fwd_ret, axis=1, method='spearman')   # 每期 RankIC

print(f"IC均值   {ic.mean():.4f}")      # >0.03 有意义, >0.05 不错
print(f"IC标准差 {ic.std():.4f}")
print(f"ICIR     {ic.mean()/ic.std():.3f}")   # >0.5 算好因子
print(f"IC胜率   {(ic>0).mean():.1%}")        # >55% 可用
print(f"t值      {ic.mean()/ic.std()*np.sqrt(len(ic)):.2f}")  # 门槛3.0
print(f"半衰期   检查 IC(1日/5日/20日/60日) 的衰减速度")

# 分组回测：看单调性
grp = factor.apply(lambda r: pd.qcut(r, 5, labels=False, duplicates='drop'), axis=1)
# 每期各组等权收益 → 累乘净值 → 看 G1<G2<G3<G4<G5 是否单调
# 多空组合(Top-Bottom)的年化、夏普、最大回撤、换手率
```

**必须做的稳健性检查**：分市值段（大/中/小盘分别测）、分行业、分时段（牛/熊/震荡）、参数敏感性（把20日改成15和25，结论是否翻转）、与已有因子的相关性（>0.7 就是重复发现）。

**危险信号**：IC>0.1、只在某一年有效、只在小盘股有效、单调性断裂、换手率极高。

### Stage 4：因子合成与模型

等权合成 → IC加权 → ICIR加权 → 最大化 IC_IR → 截面回归法 → 机器学习（LightGBM/XGBoost/NN）。
注意：**越复杂的合成方法，过拟合风险越高**。等权和IC加权在实盘中常常不输机器学习。

### Stage 5：组合构建

打分 → 优化器求解（目标：最大化 alpha，约束：行业中性偏离<2%、个股<3%、换手率<30%、跟踪误差<5%）。
简单版：选前50只等权，月度调仓。

### Stage 6：回测 → 实盘 → 归因

- 回测务必含成本，做 **Walk-forward（滚动样本外）** 而非一次性全样本内。
- 小资金实盘试运行3–6个月，计算 **implementation shortfall**（实盘 vs 回测的差距），这个差距通常比想象大得多。
- 持续监控：IC是否衰减、拥挤度是否上升、因子相关性结构是否变化。

### Stage 7：迭代

因子有生命周期。机构的做法是"因子库"管理：在研/上线/观察/退役，每季度评估。

```
第6层：迭代规则（漏了！）
   └─ 《失效条件文档》：什么情况下停用/修改这套系统
   └─ 一年只允许改一次SAA（生日那天），平时只执行
```

**你漏掉的三层（0、4、6）全是"关于你自己的约束"，你列的（1、2、3）全是"关于市场的技术"。** 这就是新手和老手的典型差异：新手框架里只有市场，老手框架里一半是自己。

## 三、IC 和 IR：公式、算法、直觉

### IC（信息系数，Information Coefficient）

**公式**（实践中用的是RankIC）：

```
ICₜ = 第t期，全体标的的【因子得分】与【未来一期收益】的 Spearman 秩相关系数
```

Python一行：`factor_t.corrwith(fwd_ret_t, method='spearman')`，对每一期算一个数，得到一个IC序列。

**直觉含义**：你的因子打分**排序能力**有多强。IC=0.05的意思是：因子说"这只比那只强"，51.25%的概率是对的，48.75%是错的——**只比抛硬币强2.5个百分点**。别嫌小，这就是真实世界里顶级因子的水平（A股月频RankIC 0.03–0.06算优秀）。

**衡量什么**：因子/模型的**预测精度**（单期截面）。

### IR（信息比率，Information Ratio）

⚠️ 先分清两个IR，很多教程混着讲：

**(a) 组合层面的IR**（衡量你的策略）：

```
IR = (策略收益 − 基准收益) 的均值 ÷ (策略收益 − 基准收益) 的标准差
   = 年化超额收益 ÷ 年化跟踪误差
```

**直觉**：你**每承受1单位的"偏离基准的风险"，换来多少超额收益**。

- 例：策略年化15%，基准10%，超额收益波动8% → IR = 5/8 ≈ 0.63
- 经验标尺：IR>0.5 算合格，>1.0 是优秀机构水平，个人跑出>2先怀疑自己回测有假。

**(b) 因子层面的ICIR**（衡量你的因子稳定性）：

```
ICIR = IC序列的均值 ÷ IC序列的标准差
```

**直觉**：因子的预测能力是**稳定**还是**时灵时不灵**。IC均值0.04但标准差0.2 → ICIR=0.2，说明大部分时间瞎猜、偶尔灵一次，不可用。ICIR>0.5才值得进组合。

### 三者的关系（量化投资基本定律）

```
IR ≈ IC × √BR
```

BR（广度）= 每年独立下注次数。

**这行公式是整套体系里最深刻的一句话**，直觉翻译：

- 你每次预测只比抛硬币强一点点（IC小）→ 没关系，**多下注、注注独立**（BR大），优势就能积累成稳定的超额收益；
- 机构：IC一般，但BR = 5000只股票×每天 → IR很高；
- 你：BR = 8只ETF×每月 = 96次/年 → √96 ≈ 10，IC需要0.05以上才有IR 0.5；
- **这就是为什么个人不要在个股高频战场和机构拼BR，而要在低频、长周期、机构不屑做的战场上拼"不被迫犯错"。**

### 附送两个你迟早要用的

```
t值 = ICIR × √期数        ← 判断"这个因子是真的还是运气"，门槛t>3
夏普比率 = (收益−无风险利率) ÷ 总波动   ← 和IR区别：IR只算超额部分的风险
最大回撤 = 净值从最高点到最低点的最大跌幅 ← 决定你实盘能不能拿住的那个数字
```

## 四、把一切串成一张执行卡（贴墙版）

```
【一次性搭好】(总共约2周)
1. 定目标约束：最多亏25%？每周2小时？钱5年不动？
2. 定SAA：如 股基65% + 黄金10% + 现金/债25%
3. 选池子：每类指数过五关（规模/成交/误差/费率/溢价），共6–8只
4. 池内定权重：波动率倒数法或核心卫星法
5. 写死规则：5pp触发带、周五检查、成本过滤、单标的≤20%
6. 写《失效条件文档》

【每周】(10分钟)
7. 周五收盘跑脚本 → 无出带 → 什么都不做（90%的周）
8. 有出带 → 生成调仓单 → 手动执行 → 记日志（含"没执行"的原因）

【每月】(30分钟)
9. 估值分位检查 → 调节定投金额
10. （进阶后）动量得分排名

【每季度】(2小时)
11. 简易归因：收益 vs 沪深300+黄金基准，超出部分才是你的本事
12. 翻一遍偏差日志，看自己有没有系统性行为毛病

【每年】(半天)
13. 生日那天审SAA和池子，其余364天禁止改规则
```

**注意这个体系里"动"的频率**：周检查10分钟、月检查30分钟、季复盘2小时。**其余时间不看不想不动**——这不是偷懒，这就是体系本身。你之前学的因子、IC、动量，都是为了让这张卡上的规则"值得相信"，而不是让你天天算这些数。
